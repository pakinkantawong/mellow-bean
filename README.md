# Mellow Bean — เว็บไซต์ร้านกาแฟ (ตัวอย่าง)

เว็บไซต์หน้าเดียวของร้านกาแฟสมมติ ทำไว้เป็นผลงานตัวอย่างสำหรับธุรกิจขนาดเล็ก
ร้าน เมนู และราคาเป็นข้อมูลสมมติทั้งหมด

## ทำอะไรได้บ้าง
- เมนูแบบแท็บ (กาแฟ / ไม่ใช่กาแฟ / ขนมอบ)
- เวลาเปิด–ปิด และสถานะ "เปิดอยู่ตอนนี้" ตามเวลาประเทศไทย
- แผนที่ OpenStreetMap (ฟรี ไม่ต้องใช้ API key) และปุ่มนำทางด้วย Google Maps
- ปุ่มโทร และปุ่มแชต LINE
- ฟอร์มจองโต๊ะ ตรวจชื่อ เบอร์ วัน และเวลาว่าอยู่ในช่วงเวลาที่ร้านเปิด แล้วส่งรายละเอียดต่อทาง LINE ได้
- ส่งข้อมูลการจองไปที่ n8n webhook ได้ (ตั้งค่าใน `config.js`)
- ธีมมืด/สว่าง และใช้งานบนมือถือได้

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ (มีส่วนอะไรบ้าง) |
| `styles.css` | หน้าตา สี และการจัดวางบนมือถือ |
| `config.js` | **ข้อมูลร้านทั้งหมด** แก้ไฟล์นี้ไฟล์เดียวเพื่อทำเป็นร้านจริง |
| `script.js` | การทำงาน: เมนู ฟอร์ม ปุ่ม และธีม |

## รันในเครื่อง
```bash
python -m http.server 8080
```
แล้วเปิด http://127.0.0.1:8080

## ทำเป็นร้านจริง
1. แก้ `config.js`: ชื่อร้าน เมนู เวลาเปิด `phone` `lineId` และพิกัด `map`
2. ตั้ง `demo: false` เพื่อซ่อนป้ายเว็บตัวอย่าง และให้ปุ่มโทร/LINE ทำงานจริง
3. (ถ้าต้องการ) ใส่ `bookingWebhookUrl` เป็น Production URL ของ n8n webhook เพื่อเก็บการจองลง Google Sheets
